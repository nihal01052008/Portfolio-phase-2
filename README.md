# Nihal — Interactive Portfolio

A cinematic, responsive developer portfolio built with semantic HTML, modern CSS, and dependency-free JavaScript.

## Highlights

- Responsive dark/light visual system
- Animated hero, ambient canvas, text scramble, magnetic actions, and 3D tilt
- Project filtering and interactive skill map
- Scroll progress, active navigation, mobile menu, and reveal animations
- Accessible labels, keyboard focus, semantic structure, and reduced-motion support
- Contact form that opens the visitor's email client without collecting data
- No build step or package installation required

## Run locally

Open `index.html` directly, or run a basic local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages

1. Replace the files in the repository with the contents of this folder.
2. Commit and push to the default branch.
3. In GitHub, open **Settings → Pages**.
4. Deploy from the default branch and repository root.

## Personal content

Update project links and profile details directly in `index.html`. Keep `profile.png`, `nihal-logo.png`, and `Resume.jpeg` beside it unless you also update their paths.
